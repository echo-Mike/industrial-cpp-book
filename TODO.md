# Лист задач для проекта

## Проработки областей

В данный момент идет поиск соавторов для проработки следующих областей:

- [ ] Промышленный опыт использования функционала корутин. Паттерны и идиомы работы с корутинами в C++
- [ ] Промышленный опыт использования функционала библиотеки ranges. Паттерны и идиомы работы с библиотекой ranges в C++
- [ ] Промышленный опыт использования функционала рефлексии. Паттерны и идиомы работы с рефлексией и генерацией кода в C++
- [ ] Промышленный опыт использования функционала контрактов. Паттерны и идиомы работы с контрактами в C++
- [ ] Промышленный опыт использования функционала экзекуторов. Паттерны и идиомы работы с экзекуторами в C++
- [ ] Промышленный опыт использования функционала C++ модулей. Паттерны и идиомы работы с C++ модулями в больших и малых кодовых базах. Поддержка C++ модулей средствами для разработки (IDE и системы сборки)
- [ ] Применение на практике функций и классов стандартной библиотеки, добавленных в стандарте C++26
- [ ] Причины и мотивы перехода со стандартной библиотеки C++ на локальные для компании имплементации или альтернативные имплементации

## Постоянные задачи

Данный проект как живая открытая книга всегда будет рад если вы опишите опыт работы с C++ в вашей индустрии. Для структуризации вашего мышления предлагаются направления:
- Какие языковые инструменты C++ вы используете в своей индустрии специфическим только доя вас образом?
- Какие инструменты стандартной библиотеки нашли необычное применение в C++ коде в вашей отрасли?
- Каких инструментов стандартной библиотеки вам не хватает из коробки чтобы написать готовое приложение в вашей отрасли?
- Какие идиомы C++ часто встречаются вами в кодовых базах?
- Какие шаблоны проектирования вы часто замечаете в коде, специфичном для вашей индустрии?

Если вам хочется, чтобы какая-то тема была освещена в книге, то откройте issue по шаблону "Предложение по добавлению контента в книгу"
